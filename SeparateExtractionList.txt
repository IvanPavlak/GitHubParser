# SeparateExtractionList.txt - Changed files that get their own diff file instead of going into Code.md
#
# A [Section] header names the output subfolder for the patterns below it.
# Each file is written to <output folder>/<Section>/<its repository path>.md,
# e.g. MD/docs/setup.md.md or Config/src/Api/appsettings.json.md.
# Leading dots are dropped from folder names (.github -> github).
#
# Same pattern syntax as Ignore.txt; the last matching line decides the section.
# Files matching Ignore.txt are never extracted.
